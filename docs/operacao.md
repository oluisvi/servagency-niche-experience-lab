# Manual local de demonstração

## Servidor estático

Use qualquer servidor estático que já esteja disponível e sirva esta pasta como raiz; os links `/demos/...` e `/assets/...` partem da raiz do site. Abra `/` para o índice. Para operação em `file://`, troque temporariamente os caminhos absolutos por relativos.

## Identidade do catálogo

O índice apresenta estudos setoriais fictícios. Páginas de clientes existentes podem ser adicionadas em novas subpastas, sempre com aprovação explícita da marca, assets e conteúdo. Mantenha o selo de estudo conceitual enquanto não houver aprovação para apresentação comercial.
