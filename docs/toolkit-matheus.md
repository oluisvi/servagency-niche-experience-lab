# Adoção do Vibe Coding Toolkit

Fonte: [soumatheusgomes/vibe-coding-toolkit](https://github.com/soumatheusgomes/vibe-coding-toolkit), clonado localmente em `toolkits/vibe-coding-toolkit/` em 2026-10-15.

Este laboratório aplicou a orquestração por áreas independentes e o registro persistente no Obsidian descritos no toolkit. A vitrine, as 40 demos e seus repositórios são estáticos; o bootstrap Next.js, Drizzle, banco de dados e testes de React do toolkit não se aplicam a essa base. Superpowers, Context7 e skills Vercel já estão disponíveis neste ambiente; instalações duplicadas não acrescentariam capacidade. O catálogo mantém o código e os assets em cada projeto, com publicação separada.

O toolkit é uma referência de fluxo, não uma dependência de runtime dos sites. O clone local está ignorado pelo Git para manter as demos leves e não redistribuir o repositório de terceiros em cada projeto.
